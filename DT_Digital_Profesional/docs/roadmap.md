# DT Digital - Roadmap

## Etapa 1 - Validacion de reglas

Objetivo: confirmar que el juego digital se comporta como el fisico.

Tareas:

- Validar tablero 5 x 10.
- Confirmar posiciones iniciales.
- Confirmar movimientos por ficha.
- Confirmar pase y remate.
- Confirmar disputa A/B/C/D.
- Confirmar remate/arquero 1/2/3/4.
- Confirmar cartas especiales.
- Confirmar duracion de partido y turno.

Resultado esperado:

- Prototipo aceptado por quienes conocen el juego fisico.

## Etapa 2 - Prototipo Unity

Objetivo: construir la primera version real en Unity.

Tareas:

- Crear proyecto Unity 6 LTS.
- Implementar motor de reglas separado de UI.
- Crear tablero digital.
- Crear fichas y pelota.
- Crear flujo de turnos.
- Crear cartas.
- Crear pausa/salida.
- Crear build Windows.

Resultado esperado:

- Partida local completa para dos jugadores.

## Etapa 3 - Presentacion profesional

Objetivo: que el juego sea presentable en eventos.

Tareas:

- Arte final del tablero.
- Fichas con identidad visual.
- Animaciones de movimiento.
- Animacion de carta.
- Efecto de gol.
- Sonido de tribuna.
- Musica/menu.
- Ajuste de camara.
- Tutorial breve.

Resultado esperado:

- Version demo para mostrar publicamente.

## Etapa 4 - IA y modos

Objetivo: permitir jugar contra la computadora y extender el uso.

Tareas:

- IA basica reglamentaria.
- IA intermedia tactica.
- Configuracion de dificultad.
- Tanda de penales.
- Historial de partido.
- Revancha rapida.

Resultado esperado:

- Version jugable solo o de a dos.

## Etapa 5 - Publicacion

Objetivo: preparar producto distribuible.

Tareas:

- Build Windows.
- Build Android para tablets.
- Optimizacion.
- QA de reglas.
- QA visual.
- Instalador o paquete portable.
- Material de presentacion.

Resultado esperado:

- Juego listo para ferias, talleres y demostraciones.
