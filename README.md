# DT Digital Profesional

Prototipo web local de DT Digital para validar jugabilidad, tablero, vestuario, tacticas, audio y flujo de partido.

## Abrir

Abrir en el navegador:

`DT_Digital_Profesional/prototipo_web/index.html`

## Version web

El repositorio queda preparado para GitHub Pages desde la rama `main` y la carpeta raiz.
La pagina principal redirige al prototipo jugable:

`DT_Digital_Profesional/prototipo_web/index.html`

## Estado

- Selector de estilo: DT Estratega y DT Intensidad.
- Registro local de equipos y validacion MFA simulada.
- Vestuario con indumentaria, tacticas, banco, charla tecnica y audio.
- Cancha jugable con cartas, disputas, remates, IA inicial y audio de partido.
- Ajustes responsive para vista de PC y dispositivo movil.
